[v3] HC_V3=absent (défaut 1) -> exécuteur v3 ACTIF
== 1. L'INTERFACE ENVOIE : hc_send_arg, comme quand on tape ==
   [msg] flèche : left
arrowKey left   pris=1
   [msg] flèche : right
arrowKey right  pris=0  (le gestionnaire fait « pass »)
   [msg] touche : a
keyDown a       pris=1
   [msg] F3
functionKey 3   pris=1
   [msg] tab
tabKey          pris=1
returnKey       pris=0  (aucun gestionnaire)

== 2. UN SCRIPT LES ÉCRIT : les dix atteignent le gestionnaire ==
   arrowKey "left"          
   [msg] flèche : left
   keyDown "x"              
   [msg] touche : x
   controlKey 1             
   [msg] ctrl 1
   functionKey 3            
   [msg] F3
   commandKeyDown "b"       
   [msg] cmd b
   enterKey                 
   [msg] entrée
   tabKey                   
   [msg] tab
   enterInField             
   [msg] entrée dans le champ
   returnInField            
   [msg] retour dans le champ

== 3. « pass » vaut DEPUIS UN SCRIPT AUSSI ==
   arrowKey "right"         
   [msg] flèche : right

== 4. SANS GESTIONNAIRE : le refus, faute d'action par défaut ==
   arrowKey "left"          
   [ERR]    !! ne sait pas faire : arrowKey "left"
   tabKey                   
   [ERR]    !! ne sait pas faire : tabKey
   returnKey                
   [ERR]    !! ne sait pas faire : returnKey

== 5. SUPPRIMER UN RACCOURCI DE MENU, touche par touche ==
   [msg] Cmd+N : supprime par la pile
Cmd+n  pris=1  -> le menu NE FAIT RIEN
   [msg] Cmd+Z : traite par la pile
Cmd+z  pris=1  -> le menu NE FAIT RIEN
Cmd+q  pris=0  -> le menu agit
   (Cmd+Q doit rester a 0 : une pile ordinaire ne doit pas
    empecher de quitter sans l'avoir voulu)

== 6. commandKeyDown DEPUIS UN SCRIPT : le message, puis le raccourci ==
   commandKeyDown "n"       
   [msg] Cmd+N : supprime par la pile
   commandKeyDown "z"       
   [msg] Cmd+Z : traite par la pile
   commandKeyDown "V"       
   -> hôte : raccourci ⌘V joué
   commandKeyDown "I"       
   -> hôte : raccourci ⌘I joué
   put "B" into k
  commandKeyDown k 
   -> hôte : raccourci ⌘B joué
