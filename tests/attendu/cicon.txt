=== 1. une icône neuve est en NOIR ET BLANC ===
   couleur : non — c'est le défaut
=== 2. la passer en couleur, et la peindre ===
   couleurs de la palette : 4
   pixels non transparents : 394 sur 1024
=== 3. LA SILHOUETTE se dérive : tout pixel peint est de l'encre ===
   bits d'encre : 394   (doit égaler le compte ci-dessus)
   les deux comptes concordent
=== 4. ALLER-RETOUR par le fichier, pixel par pixel ===
   nom          : « Terminator »
   couleur      : retrouvée
   palette      : 4 entrées, 0 différentes
   pixels       : 0 différents sur 1024
   IDENTIQUE au pixel près
   silhouette   : 394 bits d'encre relus
=== 5. LES DEUX BLOCS sont dans le fichier ===
   (iconres pour un binaire d'avant, ciconres pour la couleur :
    une pile qui gagne de la couleur ne devient pas illisible)
   iconres  : présent
   ciconres : présent
   lignes de pixels : 32   (une par ligne de l'icône)
=== 6. RETIRER la couleur garde la silhouette ===
   (l'effacer avec les couleurs ferait disparaître l'icône entière
    pour qui voulait seulement lui retirer sa couleur)
   couleur : retirée
   bits    : 394 avant, 394 après
=== 7. une icône NOIR ET BLANC n'écrit pas de bloc couleur ===
   ciconres dans le fichier : non, comme il se doit
=== 8. UN BLOC ABÎMÉ REFUSE LE FICHIER ===
   (une image complétée de zéros revient à moitié en silence ;
    on a décidé une fois pour toutes que ça n'est pas acceptable)
   relecture : refusée
   raison    : Une icône de cette pile est incomplète ou abîmée.

=== 12. LA PALETTE : poser, retrouver, deborder ===
   index 0 refuse (c'est la transparence) : refuse
   rouge -> index 1
   vert  -> index 2
   rouge de nouveau -> index 1   (la meme, pas une nouvelle)
   palette : 3 entrees
   pleine a 256 entrees ; une couleur de plus -> index 0
   (0 veut dire « choisis la plus proche toi-meme » : le noyau
    ne dessine pas, et « la plus proche » est une question de
    perception, pas d'arithmetique)
=== 13. UN PIXEL POSE MET LA SILHOUETTE A JOUR ===
   (sinon `bits` serait faux entre deux enregistrements — et
    c'est justement entre-temps que l'interface le lit pour
    afficher le bouton)
   bits au depart : 0
   apres un pixel : 1   (lu : 1)
   apres l'avoir efface : 0
   hors bornes ne deborde pas : bits = 0, lu hors bornes = 0

=== 15. COLLER UNE IMAGE DE PLUS DE 255 COULEURS ===
   (une photo, ou un degrade. La decoupe mediane construit
    255 boites, chacune rendant la moyenne de ce qu'elle
    contient. On coupe la boite la plus ETENDUE et non la plus
    peuplee : une photo a des milliers de pixels de ciel et
    quelques-uns de rouge vif, et couper par population
    noierait le rouge)
   1024 couleurs distinctes en entree -> 256 en palette
   ecart maximal sur un canal : 12 sur 255
   ecart moyen                : 4
   (un ecart maximal de quelques unites veut dire que l'oeil
    ne verra pas la difference ; c'est ce qu'on attend d'une
    decoupe qui dispose de 255 couleurs pour 1024 pixels)
=== 16. UNE IMAGE ENTIEREMENT TRANSPARENTE VIDE L'ICONE ===
   (et c'est la bonne reponse : coller du vide donne du vide,
    pas une icone noire ni un refus)
   palette : 1   pixels peints : 0   bits d'encre : 0
